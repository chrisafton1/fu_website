What sets her apart

Banned here. Banned everywhere.

Most bots stop at your server's edge: ban an account and it just joins the next server on its list. Gemma has two ways to close that gap. Both are opt-in, and both can be undone.

🌐
Ban network

Ban once, across every server you run

Link the servers you own with a private code. A ban by your mods in one lands in all of them, and lifting it travels too. Only manual bans sync, so a honeypot false positive in one server never becomes everyone's problem.

,G ban @spammer scam links
→ banned in Server A, Server B, and Server C
→ one DM to them, naming the servers
→ reason carries: "Network ban from Server A"

Gemma verifies you own every server you link. A leaked code can't attach your community to someone else's ban button.

🛰️
Global ban list

The bots that hit every server, stopped at yours

A curated list of accounts confirmed to be automated, or to friend-add members in order to solicit them. Servers opt in. A listed account that joins is DMed the reason and an appeal link, then removed before it can message anyone.

listed account joins →
→ DM: reason + appeal link
→ banned, logged, done
disagree? /gban ignore keeps them, no questions asked

Every entry carries evidence and a reason anyone can read with /gban lookup. Leave the list whenever you like. Your own staff are never touched by it.

Everything else

Eighteen features. Use the ones you need.

Nothing here is mandatory, and nothing assumes a particular kind of server. Small community? Skip the honeypot. Not recruiting staff? Skip applications.

Protection keeping the server standing

🔨

Moderation

Ban, kick, timeout, warn, purge. Use /ban, or type ,G ban @user reason and drag the screenshots onto the message. Every action becomes a numbered case, and the evidence is re-uploaded to your log so the links never expire.

🧨

Anti-nuke

When an admin account gets taken over, the damage takes seconds. Gemma counts destructive actions per person and stops whoever is doing them. Only the server owner can switch it off, which is the entire point.

🌊

Anti-raid

Ten joins in ten seconds isn't organic. Raid mode handles arrivals the way you chose, throwaway accounts can be turned away on sight, and one command raises verification to maximum while you deal with it.

🧯

Anti-spam

Rapid-fire posting, the same line five times, keyboard mash like "yousuckyousuckyousuck". Messages get cleaned up, and timeouts double for repeat offenders. Typing "lmaooooo" is still allowed.

⛓️

Jail

Somewhere between a warning and a ban. Roles come off, one channel stays visible so staff can talk to them, and everything goes back exactly as it was when you let them out. Leaving and rejoining doesn't help.

🍯

Honeypot

A channel that says, loudly, do not post here. Real members read it. Spam bots post in everything.

📝

Logging

Who deleted that message, and what did it say? Eight categories covering messages, members, moderation, channels, roles, voice, invites and server changes. Each can go to its own channel, and the responsible person comes from the audit log.

Community the reasons people stay

👋

Welcome messages

Your embed, your colours, your member count. Build it in a form, adjust the image and footer, or paste in JSON you designed elsewhere. Preview it privately before anyone else sees it.

📋

Applications

Staff applications that live in Discord instead of a Google Form. Members answer privately, your team gets Accept and Deny buttons with a note field, and the applicant hears back either way. Handing out the role stays your decision.

🎫

Tickets

One button opens a private channel between the member and your support role. Claim it so two people don't answer at once, pull someone else in, then close it. The transcript saves itself.

🎭

Reaction roles

React for a role. Group roles so people can only hold one at a time, gate a group behind a role they already have, or lock a choice once it's made. Gemma keeps the menu text and the reactions in sync herself.

🎙️

Voice channels

Join one channel and get your own, with a button panel to lock it, hide it, rename it, or throw someone out. When the last person leaves, it disappears.

☠️

Skullboard

A starboard with worse taste. Five ☠️ and the message is immortalised in its own channel, with a jump link and a live count.

Everyday small things, constantly

💬

Autoresponders

Answer the same five questions forever, automatically. Match a word anywhere in a message or only exact phrases, reply inline, and use an embed when plain text won't do.

🔰

Autorole

One role, given the moment someone joins. If a mod takes it away it stays away, and nobody who joined while Gemma was offline gets it retroactively.

⌨️

Prefix & aliases

Every mod command works as a slash command or with ,G. Make your own shortcuts too, so ,G spam @user can mean a ban with the reason already written.

⏰

Bump reminders

Thanks whoever bumped on Disboard, then pings when the two hours are up.

Getting started

Ten minutes, start to finish

  1. Invite her

    One click. The link asks for Administrator so nothing silently half-works; if you'd rather hand-pick permissions, the setup guide lists exactly which ones each feature needs.

  2. Tell her who your staff are

    /staff add @Mods. Every protective feature uses this to know who to leave alone.

  3. Run /setup

    One menu covering every channel and role a feature wants. The protection features show a status line and a single button that turns them on with sensible defaults.

  4. Try the fun parts

    /welcome test, /ticket panel, /rolemenu create, /application create name:Moderator.

  5. Change your mind whenever

    Every feature has its own commands and can be switched off without losing its settings.

Things worth knowing

🔍

She tells you when she's broken

If something fails, Gemma goes idle and says so instead of pretending everything is fine. One feature failing never takes the others with it, and there's a public status page.

🗝️

Your data stays yours

Server settings, applications, tickets and moderation records. No general chat archiving, no analytics, nothing sold to anyone. The privacy policy goes feature by feature.
